# Forever Record Keeper

Forever Record Keeper records your sessions in World of Warcraft Forever with OBS Studio.
It tags each recording from the combat log and the chat log of the game.
A library on your local network plays the video next to the log, and links each pull to Warcraft Logs.

**Status:** The project is in planning. There is no release yet.

## Features

- The library runs on your own PC. You need no account and no subscription.
- The app works with your own OBS Studio.
- The app records whole sessions, from leveling to raids.
- Tags come from the combat log and the chat log.
- Links lead to Warcraft Logs for the detailed analysis of each pull.
- The app manages the storage with a size limit, keep flags and compression.

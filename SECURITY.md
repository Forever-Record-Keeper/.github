# Security policy

## Report a security problem

Report security problems in private, through GitHub:

1. Open the repo with the problem.
2. Select **Security**, then **Report a vulnerability**.
3. Describe the problem and the steps that show it.

Don't open a public issue for a security problem.
The maintainer reads each report and answers in the same private thread.

## Areas of special interest

Forever Record Keeper runs on the gaming PC and reads files that the game writes.
Problems in these areas matter most:

- The library server on the local network, and its share links.
- The communication between the app window and the background process.
- Access to files and folders on the PC.
- Stored secrets, such as the OBS password and the Warcraft Logs tokens.
